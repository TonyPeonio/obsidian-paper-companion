First release.

- **Sync Zotero library**: reads every paper-like item from Zotero's local API (Zotero 7+, `http://localhost:23119/api/`, no token needed) or from a CSL JSON / Better BibTeX JSON export, resolves each item's PDF in the Zotero storage folder, and embeds titles and abstracts with a local embedding model (Ollama) for search by meaning. Only new or changed items are embedded on later syncs.
- **Find papers**: a search box over your library by meaning (keyword fallback when the index is empty); pick a paper to open its literature note, created on first use.
- **Related papers to this note**: the same ranking with the open note as the query.
- **Literature notes**: `Papers/<citation key>.md` with frontmatter (title, authors, year, DOI, URL, Zotero key, citation key, tags, PDF path), a citation line, the abstract, and managed *Reading notes* and *My notes* sections. Re-creating a note only adds what is missing; your text is never overwritten.
- **Write reading notes**: extracts the PDF page by page, fits the pages into the model's context window (leading pages in full, the rest sampled, every page numbered), and asks a local model for Claim, Method, Data, Results, Limitations, Key terms and Related work, every bullet cited as `[p. N]`.
- **Ask this paper**: a question answered from the pages with page citations, appended under *Q&A*.
- Nothing leaves your machine: Zotero and Ollama are both local.
