Quote search across the library, and the two connection bugs from 0.1.0 fixed.

**New**
- **Find quotes across papers.** Ask one question; the plugin ranks your Zotero library by meaning, reads the top papers' PDFs (5 by default, a setting), and writes one note under `Papers/Quotes/` with the passages that bear on the question copied verbatim, each as a blockquote with a link to the paper's literature note and the page number. Papers with nothing relevant are listed at the end, so you can see what was searched.
- **Ask this paper** quotes verbatim when you ask for wording ("quote the sentence where…") instead of paraphrasing.
- Literature notes imported by the [Zotero Integration](https://github.com/mgmeyers/obsidian-zotero-integration) plugin (frontmatter `citekey`) are recognised, so *Write reading notes* and *Ask this paper* work on them. The README explains how the two plugins fit together.

**Fixed**
- Zotero's local API was unreachable from the plugin even with "Allow other applications…" enabled: Zotero closes any connection that carries a browser `Origin` header, which Obsidian's request function adds. Zotero calls now go through Node's HTTP module. Default URL is `http://127.0.0.1:23119` (Zotero listens on IPv4 only); a saved `localhost` is switched over.
- *Test connection* for Ollama failed with "405 method not allowed": `/api/version` and `/api/tags` are GET-only and were called with POST.
